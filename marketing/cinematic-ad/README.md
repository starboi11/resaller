# Resaller cinematic ad — first cut

The owner removed this 12-second film from the storefront on 2026-09-28. Its MP4 and poster are no longer shipped in `apps/web/public/ads`. This directory retains source frames and the build script only as an archived concept; it is not part of the live page. The frames depict illustrative people, not actual Resaller users or orders.

The monochrome/crimson frames are in this directory. To rebuild on Windows, install `imageio-ffmpeg` for the current Python installation and run `build.ps1`. Intermediate clips go to ignored `test-results/cinematic-ad-render`; the script overwrites only the final ad MP4.

If a separate external advertisement is commissioned later, add properly licensed original music/voiceover and replace the still-image motion with approved full-motion footage, then review all copy and depicted claims before publication. Do not restore the storefront film without a new owner request.

Image prompt set (built-in ImageGen): photoreal Uzbekistan marketplace seller packing a product; buyer opening a parcel; seller-to-buyer parcel handoff. All three use cinematic black-and-white photography with a restrained crimson accent and contain no logos or text.
